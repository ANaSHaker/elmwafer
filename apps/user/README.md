# ElMwafer: user app

Flutter user app for **ElMwafer (وفر قريشاتك)**, a coupon and offers app backed by Cloud Firestore and FCM.
See the [main README](../../README.md) for screenshots, architecture and setup.

```bash
# Flutter 2.0–2.2 (legacy, non-null-safe code)
cp android/app/google-services.json.example android/app/google-services.json
flutter pub get
flutter run --dart-define=SUPPORT_WHATSAPP=9665XXXXXXXX
```
